等级划分：对数据的区域等级进行划分。

一级：只包含域名或IP地址，例：https://example.com / 127.0.0.1:8848。

二级：在域名或IP的下一级，例：https://example.com/test / 127.0.0.1:8848/test。



区域表（area）

| 参数名   | 表字段    | 是否必选 | 类型 | 说明                         |
| -------- | --------- | -------- | ---- | ---------------------------- |
| 数据分区 | data_area | 是       | char | 数据分区的一级分区。         |
| 权重     |           | 是       | char | 表示改数据分区数据价值占比。 |
|          |           |          |      |                              |
